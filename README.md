# ParcialReact

Aplicación de gestión de posts construida con React, Vite y Tailwind CSS. Consume la API pública [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

**Demo:** [https://m3k0h.github.io/ParcialReact/](https://m3k0h.github.io/ParcialReact/)

- Node.js 18+

---

## Instalación

```bash
# Clonar el repositorio
git clone https://github.com/m3k0h/ParcialReact.git
cd ParcialReact

# Instalar dependencias
npm install
```

## Ejecución en desarrollo

```bash
npm run dev
```

La app estará disponible en `http://localhost:5173`.

## Build para producción

```bash
npm run build
```

## Deploy a GitHub Pages

```bash
npm run deploy
```
